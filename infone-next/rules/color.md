# 颜色规则

## 基本分工

颜色先按语义分类，再选择 token：

| 类别 | token | 用途 | 禁止 |
| --- | --- | --- | --- |
| 交互色 | `--color-cta`、`--color-accent`、`--color-link` | 按钮、链接、焦点、可操作选中态和进度 | 静态区块、普通图表、位置态 |
| 状态色 | success / warning / danger / info 的 bg、fg、solid | 结果、风险、提示 | 分类和强度 |
| 数据墨色 | `--color-data-line`、`--color-data-track` | 微图表、空轨 | 文字和卡片边框 |
| 构成色 | `--color-stack-1…4`、`--color-stack-0` | 一个总量被拆分 | 独立分类 |
| 分类色 | `--th-cat-1…6-bg/fg` | 供应商、模型系列、套餐和地域 | 表达好坏或强度 |
| 强度色 | `--th-heat-0…4` | 用量、成本、延迟、活跃度 | 表达成功或失败 |
| 图表色 | `--th-chart-1…12` | 独立系列 | 状态和交互 |

## 取色决策

1. **可操作还是位置态？**
   - 可操作：使用交互色。
   - NavRail、Tree、Cascader、Pager 等位置态：使用中性 `--color-nav-selected` + `--color-fg`。
   - Steps 表达进度，不属于位置态，使用品牌色。
2. **成功、警示、危险或信息？**
   - 背景使用 bg。
   - 文字和图标使用 fg。
   - 进度条、环、圆点、时间轴节点、破坏性按钮和错误边框使用 solid。
3. **一个总量被拆分？**使用 stack 色阶和中性余量段。
4. **独立分类或系列？**
   - 图形系列使用 chart 色板。
   - 文字分类标识使用 cat 色板。
5. **表达多或少？**使用 heat 色阶；整屏最多一处，且不与内容选中底放在同一张卡里。
6. **不需强调的数据？**使用 data-line、data-fill 和 data-track。
7. **计数或小圆点？**按状态语气选择 solid，不使用品牌色。
8. **以上都不是？**使用表面或文字语义 token。

永久禁令：

- fg 结尾的 token 不能填充形状。
- solid、chart 和 stack 色不能直接写深色小字。
- 不使用营销遗留的 `--th-blue-*` 作为状态、计数、标签、按钮或图表色。
- 不跨类别借色，不就近挑一个看起来相似的 token。

## 品牌蓝

品牌蓝用于按钮、链接、焦点、Tab 指示条、可操作选中态、进度和 AI 生成态。

- 主按钮使用 `--color-cta`，默认映射到 `--brand-600`。
- `brand-500` 是身份和焦点色，不作为白字按钮填充。
- Steps 已完成使用 brand-50 + brand-600 勾，当前使用 brand-600 + 白字，连接线使用 brand-400。
- 导航和分页位置态不得使用品牌色。
- 图表、插画和语义状态不使用品牌色。
- `--color-surface-quiet` 可以是轻微品牌 tint，但它是静态表面，不带交互描边。

## 状态、分类和强度

有状态语义的对象必须使用 StatusChip、Badge 或对应状态 token。StatusChip 背景保持最浅中性底，语义通过圆点和文字表达；密集表格可以使用 plain 变体。

Tag 只在以下情况使用：

1. 字段是当前列表或卡片的扫读主键。
2. 字段同时对应页面上的可选筛选项。
3. 字段属于固定收录的分类色枚举。

其余属性使用 muted 文字和分隔符，不把 Tag 当作通用字段容器。同一属性只在一处着色。

供应商官方颜色可以使用，但必须先收录为 `--vendor-*` token。vendor 色只用于 logo、厂商身份和模型来源，不进入按钮、导航、状态或通用图表。

## 语义配额

只有页面确实存在对应语义时才要求上色：

- 有状态时，每个状态对象都使用状态色。
- 有分类集合时，使用分类色区分。
- 有强度数据时，可以使用 heat，但整屏最多一处。
- 有数据语义时，至少使用一种合适的数据图形或数据增强。
- 有信息分层时，使用一处 inset 或 quiet 区块。

简单页面没有上述语义时不硬凑非品牌色族、图形或色块。

## 视觉预算

同一屏：

- 着色语义类别不超过 3 类。
- 列表行最多包含主文本、1 个状态和 1 行次要元信息。
- 一个属性只在一处着色。
- 一张卡内最多一种内嵌底色。
- 强度或热力着色最多一处。
- MetricStrip 使用 3–4 个有效指标。
- PageHeader 使用 1 个主操作和不超过 2 个次操作。
- Tabs 不超过 5 项。

先确定这一屏的扫读主键，只给主键上色。轮次、来源、ID、时间等非主键信息降为 muted 文本；重要但不适合扫读的字段进入详情或展开区。

## 表面层级

中性表面从浅到深：

1. `--color-surface-raised`：卡片表面。
2. `--color-surface-quiet`：轻量摘要。
3. `--color-surface-inset`：代码、日志、预览、脚注和 Segmented 容器背景。
4. `--color-surface-well`：合计行或 inset 内更深一层。

同一张卡最多叠两层，且只使用一种内嵌底色。`--color-surface-selected` 是内容可取消选择时的品牌 tint；`--color-nav-selected` 是不可取消的位置态中性底。

DataTable 表头默认不使用填充底色，通过标签排版和分隔线建立层级；对比列等确需分组的场景可以使用 `--color-table-head`。

Segmented 容器使用 `--color-surface-inset`，选中滑块使用 `--color-surface`；两者通过中性表面层级区分，不使用品牌 tint 或 `--color-nav-selected`。浅色与暗色均消费现有 token 映射，实际色值以 `tokens.css` 为准。

## 对比度

- 正文和小字号文字对比度不低于 4.5:1。
- 主按钮 `--brand-600` + 白字应通过 AA；brand-500 + 白字不通过，禁止使用。
- tint 上的文字使用 brand-600、brand-700 或 gray-900。
- warning 和 danger 文字使用经过审核的深色 fg，不使用装饰色作为文字。
- 新增色阶必须同时提供暗色映射并验证相应背景上的对比度。
