# 多品牌与暗色

## 三层 token

1. 品牌层 `--brand-50…700`：产品唯一可覆盖层。
2. 语义层：`--color-accent`、`--color-link`、`--color-cta`、`--th-ring` 等，由品牌层自动派生。
3. 共享层：灰阶、系统字体、圆角、间距、阴影、动效和状态色，产品不得覆盖。

## 品牌接入

产品提交一个主身份色，由设计系统生成完整 50–700 色阶。产品不自行选择七个 stop。

接入步骤：

1. 在 `tokens.css` 之后加载 `brand.css`。
2. 只在 `:root` 覆盖 `--brand-50…700`。
3. 替换 logo 资源和展示名称。
4. 验证主按钮、链接和 tint 文字对比度。
5. 检查浅色与暗色主题。

旧的 `--th-teal-*` 只是品牌蓝兼容别名，不在新文档和新组件中继续扩散。容器级覆盖品牌色时，需要在同一作用域同步这些兼容别名；根级覆盖会自动派生。

## 色阶职责

- 50 / 100：选中 tint 和浅色背景。
- 200：需要深色标签的浅 CTA 或药丸。
- 400：连接线和弱进度。
- 500：身份、焦点和选中强调。
- 600：主按钮、链接和 tint 上可读文字。
- 700：按下和深色强调。

主按钮优先使用 brand-600 + 白字。若某个品牌色无法通过对比度，不允许通过降低标准解决；应调整生成色阶，或使用 200 填充 + 深色标签的模式。

## Logo

TopNav、NavRail 和模板通过 logoSrc 与 brand 接收品牌。不得在页面中内嵌重绘 logo。默认资源为 `assets/tokenhub-logo.svg`，展示名默认为 InfOne，具体项目可以替换。

## 暗色

- 默认生成浅色页面。
- 暗色通过 `data-theme="dark"` 切换。
- 产品不提供第二套暗色品牌色阶；暗色 tint 从 brand-400 / 500 派生。
- 不在组件或页面中手写暗色覆盖。
- 登录和错误页不会因为存在暗色 token 自动变成深色。

## 验收

- 主按钮文字、链接和 tint 文字通过 WCAG AA。
- 状态色、图表色和灰阶未被品牌覆盖。
- 品牌色没有进入导航位置态、普通图表或语义状态。
- 替换 logo 后 NavRail、TopNav、登录和结果页的尺寸与对齐不变。
